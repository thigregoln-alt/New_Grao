# Fontes

Ficheiros woff2 variáveis descarregados do Google Fonts (subconjuntos
`latin` e `latin-ext`), alojados aqui para não depender de terceiros nem
enviar o IP do visitante à Google. Declarados com `@font-face` no topo de
`css/tokens.css`.

| Ficheiro | Família | Pesos usados |
|---|---|---|
| `dm-sans-latin.woff2`, `dm-sans-latin-ext.woff2` | DM Sans | 400–700 (corpo) |
| `manrope-latin.woff2`, `manrope-latin-ext.woff2` | Manrope | 500–800 (títulos) |

Ambas as famílias estão licenciadas sob a SIL Open Font License 1.1
(https://openfontlicense.org), que permite alojá-las e redistribuí-las
com o site.
